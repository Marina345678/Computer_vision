# Обнаружение аномалий на изображениях с помощью PatchCore

## Описание проекта

Данный репозиторий содержит код и результаты проекта по обнаружению аномалий (дефектов) на изображениях. В качестве основного метода используется **PatchCore** — современный подход к unsupervised-детекции аномалий, основанный на поиске ближайших соседей в пространстве признаков.

Проект демонстрирует полный цикл: от подготовки данных до обучения модели, её оценки и визуализации.

## Наборы данных

В работе использовались два датасета для проверки обобщающей способности метода:
*   **MVTec AD** (категория `bottle`) — эталонный датасет для обнаружения аномалий.
*   **VisA** (категории `candle`, `pcb1`) — частичный набор, использовавшийся для проверки на новых данных.

*Ссылка на исходный датасет:* [https://registry.opendata.aws/visa/](https://registry.opendata.aws/visa/)

**Важно:** Исходные данные не включены в репозиторий из-за большого размера. Для запуска необходимо скачать датасеты и подготовить VisA с помощью скрипта `data_preparation.py`.

## Установка и запуск

1.  Клонируйте репозиторий:
    
    git clone https://github.com/your-username/anomaly-detection-patchcore.git
    cd anomaly-detection-patchcore

2. Установите зависимости:

pip install -r requirements.txt


3. Подготовьте данные:

Скачайте датасеты MVTec AD и VisA.

Для VisA: укажите пути в data_preparation.py и запустите его.

python data_preparation.py


4. Обучение модели:

Для MVTec AD (bottle):
Отредактируйте configs/mvtec_bottle_config.sh, указав путь к данным. Затем запустите:

sh train.sh configs/mvtec_bottle_config.sh --gpu 0
Для VisA (candle):
Отредактируйте configs/visa_candle_config.sh, указав путь к данным. Затем запустите:

sh train.sh configs/visa_candle_config.sh --gpu 0


5. Оценка и визуализация:
После обучения модель сохраняется в папке results. Укажите путь к ней в evaluate.sh и запустите:

sh evaluate.sh
